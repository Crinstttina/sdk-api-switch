# 7. 附录：自测清单

CLI 的会话记录格式、几个 `_meta` 标记、开头塞的那几块，都是内部行为。**每次升级 SDK 之前**，在一个干净的配置目录里把下面这些跑一遍，用最便宜的模型就行。

每一步都记下：缓存读了多少、写了多少、模型说了什么。

| # | 步骤 | 期望 |
|---|---|---|
| 1 | 新会话，说一句（顺便告诉它一件事，比如「我最喜欢的水果是芒果」） | `init` 里 `apiKeySource` 是 `none`；写入约等于系统提示词 + 工具 |
| 2 | 同一个进程接着说 | 几乎全读，只写新的那一点 |
| 3 | 关掉进程，用会话号 `resume` 再说一句 | 几乎全读 |
| 4 | 重铸：用后端格式的历史铸一份新会话、**带上**旧会话开头那几块，问「我最喜欢什么水果」 | 几乎全读（只写几十 token）；答对 |
| 5 | 重铸后关进程再 `resume` | 几乎全读 |
| 6 | 重铸、**不带**开头那几块 | 答对；写入比第 4 步多几百 token（就是开头那几块的差别） |
| 7 | 转工具：给一个「返回秘密数字」的工具，让它调 | 流里出现 `tool_call`；交回结果后模型说出那个数；工具名没有前缀 |
| 8 | 调完就结束：调一个标了 endTurn 的工具 | 这一轮停在工具结果上；下一句交答案（去掉开头的工具结果），模型接着说 |
| 9 | 保温：从最新一处分叉、不存、收到第一帧挂断 | 读数约等于整页，写入很少；原会话记录没多出东西 |
| 10 | 退一步：从倒数第二处 `resumeSessionAt` + `forkSession` | 读满，写入接近 0 |
| 11 | 额度探针：新进程说一句 | 收到 `rate_limit_event`，两个窗口都有数；没有走超额 |
| 12 | 按停止：一句话说到一半 `interrupt()` | `result` 是出错的子类型；桥报这个会话不能接着用 |

另外几项不必每次跑，换模型或者大版本升级时看一眼：

- 想用的每个模型各说一句，看返回里实际的 `model` 是不是你要的那个。
- 思考：自适应思考 + `display: "summarized"` 拿得到摘要和签名。
- 传了 `title` 以后，用量里不再出现起标题的那个小模型。
- 关了 `totalTokensReminder` 以后，会话记录里每句后面不再有 `<total_tokens>`。
